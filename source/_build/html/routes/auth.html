Routes détaillées

Ce module contient les routes d’authentification de l’application PlanFlan.

Routes détaillées

Routes détaillées

GET /login

Affiche le formulaire de connexion.

Description :

Affiche le formulaire de connexion pour les utilisateurs.

Exemple de réponse :

<form method="POST" action="/login">
    <input type="text" name="username" placeholder="Nom d'utilisateur">
    <input type="password" name="password" placeholder="Mot de passe">
    <button type="submit">Se connecter</button>
</form>
Status Codes:

  • 200 OK – succès

POST /login

Traite la soumission du formulaire de connexion.

Paramètres :

  • username (string) : Nom d’utilisateur

  • password (string) : Mot de passe

Réponses :

  • Redirige vers le tableau de bord en cas de succès

  • Réaffiche le formulaire avec erreurs en cas d’échec

Status Codes:

  • 302 Found – redirection en cas de succès

  • 200 OK – réaffichage du formulaire en cas d’erreur

GET /logout

Déconnecte l’utilisateur.

Description :

Déconnecte l’utilisateur et redirige vers la page d’accueil.

Status Codes:

  • 302 Found – redirection vers la page d’accueil
