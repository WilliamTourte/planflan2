Test des badges dans l'infowindow

Ce test vérifie que les badges ne chevauchent pas l'en-tête.

BOULANGERIE ❤️

Boulangerie du Coin

123 Rue Principale, Paris

Légende :

  • 🔵 Bordure bleue pointillée = zone de l'en-tête (.infowindow-header)
  • 🟡 Badge jaune = type d'établissement
  • 💙 Badge bleu = établissement labellisé

Vérifications :

  1. Les badges doivent apparaître AU-DESSUS du titre, pas sur le titre
  2. Le titre doit être entièrement visible et lisible
  3. Les badges ne doivent pas chevaucher le texte de l'adresse
  4. L'espace entre les badges et le titre doit être cohérent
